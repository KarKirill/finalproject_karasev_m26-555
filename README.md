# ValutaTrade Hub

Консольное приложение для управления валютным портфелем и моделирования операций покупки и продажи фиатных и криптовалют.

Проект разработан на Python 3.12 с использованием JSON-хранилищ, внешних API и интерактивного CLI.

## Возможности

- Регистрация пользователей и авторизация.
- Безопасное хранение паролей с использованием PBKDF2-HMAC-SHA256.
- Создание и управление валютными портфелями.
- Покупка и продажа валют.
- Проверка балансов и контроль недостатка средств.
- Получение актуальных валютных курсов.
- Загрузка курсов криптовалют через CoinGecko.
- Загрузка курсов фиатных валют через ExchangeRate-API.
- Локальное кеширование курсов с контролем актуальности.
- Хранение истории изменений валютных курсов.
- Выбор источника обновления курсов.
- Фильтрация и сортировка сохранённых курсов.
- Конвертация курсов относительно выбранной базовой валюты.
- Логирование операций и событий Parser Service.
- Ротация файлов журналов.
- Фоновое периодическое обновление курсов с помощью Scheduler.

## Технологии

- Python 3.12+
- uv - управление зависимостями и окружением.
- requests - HTTP-запросы к внешним API.
- prettytable - форматирование консольных таблиц.
- argparse - разбор аргументов CLI.
- JSON - хранение данных.
- logging - журналирование.
- Ruff - проверка качества и форматирование кода.

## Архитектура проекта

Проект разделён на несколько основных компонентов.

### Core Service

Содержит бизнес-логику приложения:

- `currencies.py` - иерархия валют и реестр поддерживаемых валют.
- `exceptions.py` - пользовательские исключения приложения.
- `models.py` - модели пользователей, кошельков и портфелей.
- `usecases.py` - регистрация, авторизация, покупка, продажа и получение курсов.
- `utils.py` - вспомогательные функции работы с курсами.

### Parser Service

Отвечает за получение, обработку и сохранение валютных курсов:

- `config.py` - конфигурация API и параметров обновления.
- `api_clients.py` - клиенты CoinGecko и ExchangeRate-API.
- `updater.py` - получение и объединение курсов из источников.
- `storage.py` - работа с кешем и историей курсов.
- `scheduler.py` - периодическая проверка актуальности курсов и фоновое обновление.

### Infrastructure

- `settings.py` - загрузка настроек из `pyproject.toml`.
- `database.py` - единая точка доступа к JSON-хранилищам, атомарная запись и синхронизация доступа.

### CLI

- `commands.py` - настройка и разбор пользовательских команд.
- `interface.py` - интерактивный консольный интерфейс.

### Дополнительные модули

- `decorators.py` - декоратор журналирования доменных операций.
- `logging_config.py` - настройка файлового и консольного логирования.
- `main.py` - точка входа приложения.

## Установка и запуск

### Требования

- Python 3.12 или новее.
- Установленный пакетный менеджер uv.
- Доступ к интернету для получения курсов через внешние API.

### Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/KarKirill/finalproject_karasev_m26-555.git
cd finalproject_karasev_m26-555
```

Установите зависимости:

```bash
uv sync --dev
```

### Запуск приложения

```bash
uv run project
```

Альтернативный способ запуска:

```bash
uv run python main.py
```

После запуска откроется интерактивная консоль ValutaTrade Hub.

Для просмотра доступных команд используйте:

```text
ValutaTrade> help
```

## Настройка внешних API

### CoinGecko

Используется для получения курсов криптовалют:

- BTC - Bitcoin.
- ETH - Ethereum.
- LTC - Litecoin.

Адрес API по умолчанию:

```text
https://api.coingecko.com/api/v3
```

Ключ API в текущей конфигурации приложения не требуется.

### ExchangeRate-API

Используется для получения курсов фиатных валют:

- USD - US Dollar.
- EUR - Euro.
- RUB - Russian Ruble.
- GBP - British Pound.

Для работы необходимо получить API-ключ ExchangeRate-API и задать переменную окружения.

PowerShell:

```powershell
$env:EXCHANGE_RATE_API_KEY = "YOUR_API_KEY"
```

После этого запустите приложение:

```powershell
uv run project
```

Переменная окружения задаётся для текущей сессии PowerShell. При открытии нового окна её необходимо установить повторно.

Не добавляйте настоящий API-ключ в Git-репозиторий.

## Основные команды CLI

### Регистрация и авторизация

Регистрация пользователя:

```text
ValutaTrade> register Kirill
```

Авторизация:

```text
ValutaTrade> login Kirill
```

При отсутствии параметра `--password` пароль вводится интерактивно.

Также поддерживается именованная форма аргументов:

```text
ValutaTrade> register --username Kirill
ValutaTrade> login --username Kirill
```

### Управление портфелем

Просмотр портфеля:

```text
ValutaTrade> show-portfolio
```

Просмотр портфеля с оценкой в EUR:

```text
ValutaTrade> show-portfolio --base EUR
```

Для выполнения операций с портфелем необходимо авторизоваться.

### Покупка и продажа валют

Покупка:

```text
ValutaTrade> buy BTC 0.01
```

Альтернативная форма:

```text
ValutaTrade> buy --currency BTC --amount 0.01
```

Продажа:

```text
ValutaTrade> sell BTC 0.005
```

Альтернативная форма:

```text
ValutaTrade> sell --currency BTC --amount 0.005
```

### Упрощённая модель торговли

В проекте используется упрощённая модель торговли валютами:

- **Покупка валюты** увеличивает баланс соответствующего кошелька.
- **Продажа валюты** уменьшает баланс соответствующего кошелька.
- USD используется в качестве базовой валюты исключительно для расчёта оценочной стоимости активов и отображения курсов.
- При покупке и продаже валюты списание или начисление средств в USD не производится.

Все торговые операции являются симуляцией и не предполагают проведения реальных денежных переводов.

### Получение валютного курса

Получение курса BTC относительно USD:

```text
ValutaTrade> get-rate BTC USD
```

Именованная форма:

```text
ValutaTrade> get-rate --from BTC --to USD
```

### Обновление курсов

Обновление курсов из всех источников:

```text
ValutaTrade> update-rates
```

Только CoinGecko:

```text
ValutaTrade> update-rates --source coingecko
```

Только ExchangeRate-API:

```text
ValutaTrade> update-rates --source exchangerate
```

### Просмотр сохранённых курсов

Все сохранённые курсы:

```text
ValutaTrade> show-rates
```

Курс конкретной валюты:

```text
ValutaTrade> show-rates --currency BTC
```

Курсы относительно EUR:

```text
ValutaTrade> show-rates --base EUR
```

Топ-3 криптовалют по стоимости:

```text
ValutaTrade> show-rates --top 3
```

Параметры `--currency` и `--top` нельзя использовать одновременно.

### Служебные команды

```text
ValutaTrade> help
ValutaTrade> exit
```

## Хранение данных

Все основные данные приложения хранятся в каталоге `data/`.

| Файл | Назначение |
|---|---|
| `users.json` | Учётные записи пользователей |
| `portfolios.json` | Пользовательские портфели и кошельки |
| `rates.json` | Локальный кеш актуальных курсов для Core Service |
| `exchange_rates.json` | История полученных валютных курсов Parser Service |

Для обеспечения целостности данных используется `DatabaseManager`, реализующий:

- централизованный доступ к JSON-хранилищам;
- атомарную запись файлов;
- синхронизацию операций;
- безопасную обработку ошибок чтения и записи.

## Конфигурация

Основные параметры задаются в секции `[tool.valutatrade]` файла `pyproject.toml`.

| Параметр | Значение по умолчанию | Назначение |
|---|---|---|
| `data_dir` | `data` | Каталог данных |
| `base_currency` | `USD` | Базовая валюта |
| `rates_ttl_seconds` | `3600` | Время актуальности кеша |
| `api_timeout` | `10` | Таймаут API-запроса |
| `scheduler_interval_seconds` | `60` | Интервал Scheduler |
| `log_dir` | `logs` | Каталог журналов |
| `log_level` | `INFO` | Уровень логирования |

Scheduler реализован как отдельный компонент и не запускается автоматически при старте CLI.

## Логирование

Приложение использует два основных журнала:

- `logs/actions.log` - журнал действий приложения.
- `logs/parser.log` - журнал работы Parser Service.

Для файловых журналов применяется `RotatingFileHandler` с ограничением размера файла и хранением резервных копий.
